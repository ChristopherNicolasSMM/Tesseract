# Relatórios

A área Relatórios permite criar modelos com textos e tabelas, associar campos aos dados enviados e conferir o documento em PDF antes de publicar. Nesta primeira construção, os modelos são compartilhados com as pessoas que têm permissão para acessá-los.

A tela já foi construída, mas a entrega ainda aguarda revisão visual e integração com relatórios reais. Não há pacote para instalar nesta etapa.
