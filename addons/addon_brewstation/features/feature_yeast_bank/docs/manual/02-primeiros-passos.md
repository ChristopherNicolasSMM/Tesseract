# 02 — Primeiros Passos (Yeast Bank)

1. Acesse a área "Banco de Levedura" no menu.
2. Clique em "Nova Cepa" e preencha pelo menos o nome (ex.: "US-05").
3. Se for guardar fisicamente (congelada, em slant), cadastre um
   "Item do Banco" vinculado a essa cepa.
4. Se você tem um Dispositivo de armazenamento (freezer com sensor),
   vincule-o ao item — as leituras de temperatura passam a entrar
   automaticamente no cálculo de viabilidade.
5. Sempre que fizer um starter com essa cepa, registre em "Starters" —
   é outra fonte de referência pro cálculo.
