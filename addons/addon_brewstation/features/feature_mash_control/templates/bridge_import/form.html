O que a importação faz
  1. Cada device do devices.yml vira uma Function + um Ator de dispositivo (addon_device_manager).
  2. Cada vessel do recipe.yml vira um Tanque, com os Mapeamentos (sensor/aquecedor/bombas) já ligados às Functions certas — é o "de-para" pronto.
  3. As bombas usadas entre etapas de tanques diferentes viram uma tentativa de tubulação (editável depois).
  4. Um Layout de Dashboard é criado com um widget "tanque" por tanque + uma lista de alarmes.

Nada é sobrescrito — rodar de novo só acrescenta o que ainda não existe.
