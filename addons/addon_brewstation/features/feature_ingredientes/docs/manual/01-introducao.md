# 01 — Introdução

Ingredientes é onde ficam as especificações técnicas usadas no cálculo
de receitas — cor e rendimento de maltes, alfa-ácidos de lúpulos,
floculação e atenuação de leveduras. Cada especificação está ligada a
um Material do Estoque (é o Material que controla o SKU e a
quantidade em estoque; aqui ficam só os dados técnicos usados nas
receitas).
