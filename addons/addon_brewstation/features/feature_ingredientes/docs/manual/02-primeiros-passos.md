# 02 — Primeiros Passos (Ingredientes)

1. Cadastre o Material correspondente no Estoque primeiro (ex.:
   "Malte Pilsen") — é ele que aparece na busca ao criar a
   especificação técnica.
2. Acesse "Ingredientes" no menu e escolha Maltes, Lúpulos ou
   Leveduras.
3. Clique em "Novo registro", busque o Material já cadastrado no
   campo de busca, preencha os dados técnicos (cor, alfa-ácidos,
   atenuação — o que se aplicar ao tipo) e salve.
