# 04 — Perguntas Frequentes (Ingredientes)

**P: Cadastrei um Malte mas não encontro o Material dele na busca.**
R: O Material precisa existir primeiro, cadastrado na tela de
Materiais (Estoque). Cadastre-o lá antes de voltar pra tela de
Ingredientes.

**P: Qual a diferença entre o Material e a especificação (Malte/
Lúpulo/Levedura)?**
R: O Material controla estoque (quanto você tem, código, fabricante).
A especificação guarda só os dados técnicos usados no cálculo da
receita (cor, amargor, etc.) — as duas coisas ficam ligadas, mas são
telas separadas.
