# 02 — Primeiros Passos (Envase)

1. Garanta que os materiais de embalagem (garrafa, tampinha, rótulo,
   etc.) já estão cadastrados no Estoque, com saldo suficiente.
2. Acesse "Envase" no menu e clique em "Novo registro" em "Envases".
3. Informe o lote de origem e a quantidade envasada.
4. Em "Itens de Envase", registre cada material de embalagem usado e
   a quantidade — o estoque de cada um é descontado assim que você
   salva.
