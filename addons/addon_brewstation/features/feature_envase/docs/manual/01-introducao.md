# 01 — Introdução

Envase é onde você registra o empacotamento de um lote — garrafas,
latas, barris — e os materiais de embalagem usados nesse processo
(tampinhas, rótulos, caixas). Ao registrar um envase, o estoque dos
materiais de embalagem usados é descontado automaticamente — você não
precisa lançar uma movimentação de saída separada no Estoque.
