# 04 — Perguntas Frequentes (Integração BrewFather)

**P: Apaguei uma receita importada por engano — como trago ela de
volta?**
R: Vá em "Selecionar Receitas pra Sincronizar" — ela vai aparecer com
o selo "Apagada — pendente de reimportar". Marque e sincronize de
novo; volta como uma nova versão.

**P: Preciso resolver o de-para toda vez que sincronizo?**
R: Não. Só na primeira vez que um ingrediente com aquele nome
aparece. Depois de resolvido uma vez, qualquer receita futura com o
mesmo ingrediente já vem ligada automaticamente.

**P: Qual a diferença entre buscar um Material existente e cadastrar
um novo?**
R: Buscar um existente liga o ingrediente a um Material que você já
tem cadastrado (evita duplicar). Cadastrar um novo cria um Material do
zero — útil se for a primeira vez que esse ingrediente aparece no
sistema.

**P: Usei "Cadastrar todos automaticamente" e agora tenho vários
materiais "pendente de revisão" — isso é um problema?**
R: Não é um erro. É só um lembrete de que os dados desses materiais
foram preenchidos automaticamente e podem valer a pena revisar quando
tiver tempo (fabricante, código de barras, etc.) — eles funcionam
normalmente enquanto isso.
