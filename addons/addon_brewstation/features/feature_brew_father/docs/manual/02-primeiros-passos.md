# 02 — Primeiros Passos (Integração BrewFather)

1. Acesse "Integração BrewFather" no menu.
2. Duas formas de trazer receitas:
   - **Sincronizar Tudo** — importa todas as receitas da sua conta de
     uma vez.
   - **Selecionar Receitas pra Sincronizar** — mostra a lista de
     receitas disponíveis, com um aviso de status em cada uma (Nova /
     Já importada / Apagada — pendente de reimportar), e você escolhe
     quais importar agora. Use esse quando não quiser trazer tudo de
     uma vez.
3. Se aparecer o botão "Pendentes de Resolução", clique nele — é a
   tela de-para, onde você liga cada ingrediente importado a um
   Material do Estoque.
4. Pra cada ingrediente pendente, busque um Material já existente
   (digite o nome no campo de busca) ou digite um nome novo pra
   cadastrar um Material na hora. Confirme.
5. Repetiu o mesmo ingrediente em outra receita? Não precisa resolver
   de novo — a ligação já feita é lembrada automaticamente.
